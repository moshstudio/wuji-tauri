## Default Permission

Default permissions for the cast plugin

#### This default permission set includes the following:

- `allow-discover-devices`
- `allow-cast-media`
- `allow-cast-control`
- `allow-get-cast-state`
- `allow-stop-cast`
- `allow-get-lan-ip`
